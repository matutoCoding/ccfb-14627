# 单晶衍射实验规划台

浏览器内运行的四圆单晶衍射实验规划与预测系统。纯 TypeScript + WebGL2，无运行时框架依赖，样品与实验记录全部保存在本地（localStorage + IndexedDB），不发任何网络请求。

## 启动

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm test       # 40 项几何/消光/策略单元测试
pnpm build      # 类型检查 + 生产构建
```

## 页面与需求对应

| 页面 | 覆盖需求 |
| --- | --- |
| 样品登记 | 按课题组登记，晶胞/尺寸/外形/镶嵌度/波长弥散，内置 4 个演示晶体（NaCl、金红石、蔗糖、孪晶样） |
| 晶胞与对称 | 晶胞参数、40 个常用空间群及精确消光规则、Euler 取向、原子位点、孪生律 |
| 收集策略 | ω/φ 扫描段编辑、完整度/冗余度/分辨率壳层实时统计、贪心集合覆盖自动规划、排期联动 |
| 衍射图预测 | Ewald 解析求交、平板探测器投影、转角时间轴、进出角标注、空气散射/挡光锥背景 |
| 倒易空间 | 3D 轨道视图、按 rocking 中心角着色、hk0/h0l 等任意层切片、盲区统计 |
| 设置 | 仪器默认值、主题、实测帧导入与预测叠加比对、数据导出/重置 |

## 几何约定（精度红线的根基）

- 倒易矢量不含 2π：`a* = (b×c)/V`，故 `|r_hkl| = 1/d`
- 实验室坐标：X 水平、Y 竖直向上、Z 沿入射光方向；`k0 = (0,0,1/λ)`
- Ewald 方程：`|r|² + 2·k0·r = 0`
- 测角仪：Euler z-x-z，`U = Rz(φ)Rx(κ)Rz(ω)`；ω 轴与 φ 轴均随 κ 臂倾斜，避免与光束重合的几何盲区
- 求交：绕固定轴旋转时，Ewald 方程化为 `A + B·cosθ + C·sinθ = -ρ²/2`，每转最多两个解析 Bragg 中心，无迭代误差
- 全部几何判定在 JS 端用 f64 完成，GPU 只负责绘制；最终顶点才转 f32

### 三条红线如何保证

1. **亚像素精度**：`ewald.test.ts` 用手算的 (100) 反射对标，探测器投影偏差断言 `< 0.5 px`，并验证 Ewald 等式在机器精度成立
2. **系统消光零漏检**：消光检查在反射生成阶段执行，被剔除的反射不进入任何渲染缓冲；F/I/C/R 点阵与螺旋/滑移规则各有独立测试
3. **时间轴不闪不跳**：反射表一次生成、槽位固定，时间轴只通过 `bufferSubData` 更新实例缓冲的位置/偏心率，斑点身份与顺序不变；偏心率用高斯函数在 ±2 FWHM 内淡入淡出

## 目录结构

```
src/physics/   纯函数几何内核（可独立测试，不碰 DOM）
  math3d            f64 矢量/矩阵
  lattice           正/倒易晶胞、Bragg 角
  orientation       Busing-Levy 取向与测角仪转轴
  ewald             Ewald 解析求交、rocking 窗口、偏心率
  detector          平板投影、帧斑点生成、孪晶重叠标记
  spacegroup_*      消光规则、对称操作闭包、空间群注册表
  structure_factor  Cromer-Mann 散射因子、Debye-Waller、LP 校正
  reflection        反射表生成（含孪晶畴）
  strategy/auto     完整度统计与最省机时优化
  twin/background/schedule
src/render/    WebGL2 渲染器（探测器实例化斑点、倒易空间 3D）
src/ui/        响应式 store、外壳、六个页面
src/data/      localStorage / IndexedDB 持久化、演示晶体
```

## 空间群实现口径

- 消光规则对全部 40 个群精确生效并有测试守护，这是结构正确性的红线
- 一般位置对称操作用「点群闭包 + 点阵平移陪集展开」生成；核心教学群（P-1、P2₁、P2₁2₁2₁、Fm-3m、R-3 等）的阶数有锁定测试
- 少数含 1/3 螺旋平移的群（P3₁21 等）精确阶数未锁定，仅保证消光正确；UI 会对未内置完整对称操作的群给出提示
